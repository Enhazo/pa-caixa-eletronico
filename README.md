# Caixa Eletrônico

Exercício em C++ que simula operações básicas de caixa eletrônico: consulta de saldo, depósito, saque com confirmação, resumo e exportação de relatório em TXT/CSV.

## Compilação

Projeto desenvolvido para Windows e usa APIs do Windows. Compile `caixa-eletronico.cpp` em um compilador C++ para Windows.

Autor: [@Enhazo](https://github.com/Enhazo)


## Versão histórica adicional

A pasta `historical/` contém uma variante do exercício com resumo das operações e exportação do relatório para `saldo.txt`. Ela é mantida separada da versão principal; requer compilação e execução em Windows por usar `system("cls")` e `system("pause")`.
